index.html : L1865-1907
為什麼製作在這裡？ (Design Rationale)

捨棄易發生影格堆疊與後台狂奔的 setInterval，全面採用瀏覽器原生的 requestAnimationFrame。當頁面處於背景標籤時自動休眠節省電力，重回焦點時與螢幕垂直同步信號（VSync）同步刷新。

  • 調度機制：requestAnimationFrame(loop) 遞迴
  • 時間步長：delta = timestamp - lastTimestamp
  • 休眠機制：背景頁面自動降頻省電
index.html (JavaScript) Lines 1865-1907 
startRenderLoop() {
  const loop = (timestamp) => {
    const delta = timestamp - this.lastTimestamp;
    this.lastTimestamp = timestamp;
    // 推進時間軸與影格耗時統計
    requestAnimationFrame(loop);
  };
  requestAnimationFrame(loop);
}

關鍵參數與工程規格 (Parameter Specs)

  • 物理過衝：y2 = 1.56 (超越 1.0 的彈性位移)
  • 作用對象：按鈕 hover/active、星標、抽屜動效

  • 檔案體積：0 KB (純代碼合成)
index.html (JavaScript) Lines 1528-1549 
playClick() {
  const now = this.ctx.currentTime;
  const osc = this.ctx.createOscillator();
  const gain = this.ctx.createGain();
  osc.frequency.setValueAtTime(1200, now);
  osc.frequency.exponentialRampToValueAtTime(300, now + 0.07);
  gain.gain.exponentialRampToValueAtTime(0.001, now + 0.07);
